Tiro de Hambúrguer 

Sobre o projeto

O Tiro de Hambúrguer é um site criado para representar uma hamburgueria fictícia, inspirado no universo da franquia Grand Theft Auto (GTA).
A proposta é apresentar uma página web com visual personalizado, destacando a identidade da hamburgueria e seus produtos.

Tecnologias utilizadas

HTML5
CSS3
JavaScript (se utilizado no desenvolvimento)

Como acessar o projeto

1. Entre no repositório do projeto no GitHub.
2. Faça o download dos arquivos disponíveis.
3. Abra a pasta do projeto utilizando o Visual Studio Code.
4. Localize o arquivo `index.html` e abra-o em um navegador.
